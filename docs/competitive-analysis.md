# Analyse concurrentielle — Housat

Synthese de la recherche marche (sept. 2026). Conclusion : aucun acteur ne fait du suivi satellite B2C dedie a la construction residentielle individuelle. Les briques de rentabilite sont prouvees separement.

## Modeles B2C/prosumer viables

| Acteur | Modele | Prix | Lecon pour Housat |
|---|---|---|---|
| SpyMeSat (Orbit Logic, US) | achat in-app a l'unite, tasking | image HR a l'acte | l'UX self-serve grand public fonctionne |
| SkyFi (US) | pay-per-image sans contrat | archive ~5-15 $, analytics 5$/analyse, Sentinel gratuit | reste horizontal (« your house »), pas de produit chantier |
| GammaEarth (Croatie) | superresolution IA du Sentinel-2 gratuit, 2 EUR/credit = 1 km2 | panier min 200 EUR | LE levier : input 0 $ => cout marginal ~2 EUR/verification |
| NILAMorbit / LandWatch (Inde) | parcelle -> alerte de changement, SMS revendication | B2C proprietaires | preuve de willingness-to-pay B2C verticalise |
| Terra Trace IQ (US) | B2B preteurs/promoteurs, rapport PDF chaque lundi | 149 $/site/mois | prix de marche du rapport hebdo |
| SkyWatch (CA) | API donnees, HR des 10 $/km2 | min 1 km2 | couteux si imagerie commerciale — a eviter en B2C |

## Loi economique du secteur

La rentabilite B2C satellite depend d'un seul levier : le cout de la donnee d'entree.

- Sentinel-2 gratuit + superresolution IA => verification ~2 $ => offre 29 $/mois/chantier largement rentable.
- Imagerie commerciale 50 cm (7-12 $/km2, min 25 km2) => casse le B2C pur ; reservee en upsell ponctuel (verification de litige, ~15 $/image via SkyFi en marque blanche, phase 3).

## Positionnement Housat

Assemblage inedit : GammaEarth (cout) x NILAMorbit (alerte parcelle) x Terra Trace (rapport hebdo) — applique au chantier de maison individuelle pour la diaspora. Jalons M0-M4 detectes automatiquement : fondation, structure, toiture, finition.
